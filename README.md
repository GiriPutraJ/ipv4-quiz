# IPv4 VLSM Quiz

Mode kuis berbasis HTML, CSS, dan JavaScript.

Fitur:
- soal IPv4 dan CIDR random
- input Network ID, Subnet Mask, Broadcast ID, First Usable Host, Last Usable Host
- penilaian benar/salah per jawaban
- skor 0–5
- persentase nilai
- jumlah percobaan
- timer
- timer berhenti saat semua jawaban benar
- tombol Reset Kuis
- tombol Generate Soal Baru

Jalankan langsung dengan membuka index.html atau gunakan:

python -m http.server 8000

lalu buka http://localhost:8000
